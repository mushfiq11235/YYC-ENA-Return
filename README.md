# 🚗 YYC Vehicle Return Guide

A simple, bilingual (English / Français) guide that helps customers return a rental vehicle at Calgary International Airport.

**Features**
- 🗺️ Photo walkthrough of the route to the return lanes
- 🕓 Live "agents on-site / after-hours" status in Calgary time
- ✅ Return checklist, accident paperwork helper, and lost-item email draft

**Tech:** one self-contained `index.html`. No build step, no dependencies, no tracking.

**Run it:** open `index.html` in a browser, or host it with GitHub Pages.

> Unofficial guide. Always follow airport signs and staff directions.

Link to website: https://mushfiq11235.github.io/YYC-ENA-Return
